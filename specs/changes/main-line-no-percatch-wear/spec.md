# 主线取消按尾耐久损耗

Status: done

## Problem Statement

旧 `wearPerCatch["line"]` 在每次成功钓获时额外扣除 0.0015 耐久。官服搏鱼磨损对拍只观察到按受力时间结算，没有“每尾鱼固定扣一笔”的主线磨损通道；该额外损耗会让主线寿命明显短于官方表现。

## Solution

仅将 `wearPerCatch["line"]` 设为 `0`。主线/前导仍保留原有非按尾损耗：

- 断线、剪线按米数扣主线；
- 前导继续走搏鱼受力秒磨损通道。

鱼钩、竿本体、浮漂、拟饵及其它组件的按尾速率保持不变，不在本改动中调整。

## User Stories

1. 连续成功钓获不会凭结算次数额外消耗主线耐久。
2. 断线和剪线仍按既有米数规则损失主线。
3. 前导的搏鱼受力磨损不受影响。
4. 竿本体等其它既有按尾磨损保持原行为，便于独立回退。

## Implementation Decisions

- 只修改 `internal/gameserver/econ_market.go` 的 `wearPerCatch["line"]`。
- 不新增按咬口磨损通道，不修改软饵、泡沫饵、鱼钩或其它装备的磨损参数。
- 不追溯已磨损存档，无数据库迁移。

## Testing Decisions

- 使用真实钓获结算验证主线耐久保持不变。
- 同一次结算中验证竿本体仍按原有按尾速率下降，防止误把其它组件一起停扣。
- 完成门禁：`go test ./...`、`go vet ./...`、`go build ./...`、doccheck。

## Out of Scope

- 不调整主线断线/剪线米数损耗。
- 不调整前导受力秒磨损速率。
- 不调整鱼钩、浮漂、拟饵、竿本体或轮体磨损。

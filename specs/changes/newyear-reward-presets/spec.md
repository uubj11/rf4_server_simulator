# 新年活动奖励预设

Status: done

当前后台提供 2025、2026 新年预设。2024 新年仅支持手动配置；下文的 2024 清单作为旧配置记录。

## Problem Statement

新年预设仍显示待核实；现已整理 MMXXV、MMXXVI 固定奖励及 MMXXIV 阶段福袋编号，需要转为管理员可选择的配置，并验证实际领取和开包。

## Solution

沿用 event_stage_gifts、每年独立 JSON 及已有填入/保存流程。2025、2026 覆盖普通 7 阶段、特别版 10 阶段和全部完成奖励。2024 普通与特别版的 1..7 对应同号福袋；按用户 2026-11-18 的明确选择，把已整理的旧福袋物品重新按任务难度配置为固定清单，每阶段全量发放，不做概率抽奖。通过现有阶段发奖链路直接兑现内容；真实固定套装保留本体供玩家打开。此为模拟服自定义全量版本，不宣称与官方随机福袋规则相同。

## User Stories

- 管理员按年份填入奖励，保留已有配置，保存后沿用阶段完成领取机制。
- 玩家领取固定礼盒后打开得到静态定义中的内容，重复巡检或打开不能重复发奖。
- 普通与特别版分别按实际阶段数完成；2025/2026 特别版最终装备仅在全部完成后发放。2024 自定义版按难度把三种限定轮分别放在会员第 5/6/7 阶段，每种固定发一次。

## Implementation Decisions

- 创建 newyear-2025.json（13/14）与 newyear-2026.json（17/18）；0 为全部完成奖励，纪念奖杯沿用独立机制。
- 2025 依据用户指定的 GameKee 奖励记录；2026 依据用户指定视频中的 MMXXVI 奖励，允许沿用 NY25 商品，不根据标题改年份。
- 未显示发放数量的条目按一个完整商品预设，可由管理员调整；2026 的精确发放数量和旅行时长未获得官服回执验证。礼盒 qty=1，保留本体，内容和单位量沿用静态定义；咖啡 qty=50；2025 来源明确两瓶冰酒，每瓶两份，qty=4；2026 按一完整瓶 qty=2。三天会员沿用直接到账。
- 2026 特别版完成奖励为 cast_10148_CF77XH_NY26 与 bcr_6049。第一阶段氟碳套装采用无 2025 后缀的 fluoro_nys_pack，其三卷内容与 2025 版相同。
- 实际领取测试发现 ny_mitts（类别 21）没有实例映射，原先回落为钓线。补为 bdbcnhkogcc/113，字段使用现有 wire_spec，不新增字段或改数组；依据唯一匹配的六个服装属性及定义 peomolgjoeh/12017，proto.ps1 已核对两类的字段。客户端基线 4.0.25034；尚无该手套官服领取报文，需实机验证背包显示、领取与穿戴，不宣称已验证官服响应。
- 旧 2024 配置样例（9/10），各 7 阶段，无额外 stage=0 物品；奖杯仍走既有机制。已观察到的不同开袋结果全部纳入活动固定奖励。按用户随后提出的难度递进要求重新分配阶段：普通第 1 阶段发 3 天会员与柠檬水礼盒，终阶发限定手竿与标本券；会员 5/6/7 分别发 R605、博雷 30、大蓝 Venga，每种一件。不含权重、概率或候选分支。
- 2024 数量：浮漂 3 个，咖啡/蜂蜜各 50 份，冰酒/白兰地/辣椒伏特加各 2 份；套装各一盒，单卷 Powerline 为 100 米完整线卷。柠檬水采用目录 lim_ny_pack_6 候选映射。旧会员 5 船票无确切种类，暂未配置，不任意填入某种船票。
- 2024 不创建 category 73 的背包实例，不新增开袋协议。任务面板直接预览并发出清单内物品；后台沿用逐物品编辑、只填空缺及显式保存行为。用户自定义配置不自动覆盖，运行中的玩家库不自动写入。
- 相比上一轮提出的权重抽奖方案，用户明确改为全部发放，故不新增奖池接口或权重编辑器。
- 实施步骤：先补资源合法性、全阶段领取和开包测试并确认失败；新增预设及界面；运行针对性和全仓检查；回填实测结果。

## Testing Decisions

- 真实静态库校验预设嵌入、接口可读、完整商品及阶段覆盖。
- 真实测试玩家逐阶段领取，未达标不发、完成奖励不提前、重复领取不增发；检查咖啡/冰酒实际数量、礼包开启与重放。
- 浏览器验证按年/全部填入、保留用户配置、未开启分支不填、无自动保存，1280/360 宽度。
- go test ./...、go vet ./...、go build ./...、go run ./tools/doccheck。

验证结果（2026-11-18）：`go test ./... -parallel 4` 通过，gameserver 208.731s；`go vet ./...`、`go build ./...` 通过。doccheck issues=0，既有 bite 文档长度软提示 1 条。Playwright 后台测试在 1280/360 宽度通过，15.7s。测试使用临时玩家库，没有修改运行中的玩家进度或奖励配置。

2025/2026 预设、38 项阶段/完成奖励、领取幂等和全部配置礼包的开启已通过服务端验证。独立评审未发现新增逻辑错误；2026 手套仍缺客户端领取、显示、穿戴及真实报文验证。未部署运行服务。2024 改按用户指定的固定全量方案交付；本轮验证结果见下方，旧袋完整官方数据不属于本轮完成判据。

### 2024 难度递进固定清单

资源用于核对真实存在的物品，任务条件用于确定模拟服奖励档位；没有宣称资源里有官方稀有度表。普通线前期集中在两个新手水域，中期增加手竿、夜钓与目标重量要求，终阶要求稀有鱼及 15 种鱼。会员线后期涉及鳗鱼、廓里湖白鲑、哲罗鱼和 5 公斤黑鲩。因此把限定装备放在后期，每种限定轮发放一次。普通线第 1 阶段发放 3 天会员。
